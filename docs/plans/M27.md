# M27 · Zone gaps, part 2

## Plan

**Goal (closing gaps from M20):** export a branch or a zone from `nexus export` and the
MCP `export` tool, copy several zones at once, carry callouts through copy and paste,
and keep topic paste from treating a lookalike document as its source.

**Accept when:**
- **A1 · Headless scopes:** `nexus export` and the MCP `export` tool take a branch (a
  topic id, path or title), a zone (id or title), or every zone: a file each, like the
  export sheet's Zones picker (D195), or for PDF one file with a page per zone. Without a
  scope, the output is exactly as before. `nexus --help` lists the options. Selection
  isn't offered (there's no window).
- **A2 · Several zones:** ⇧- or ⌘-click selects several zones, and ⌘C, ⌘X and ⌘D take
  them together; rubber-band too if it fits the selection model, or why not is recorded.
- **A3 · Callouts:** callouts on copied topics travel with topic copy and zone copy, with
  fresh, remapped ids.
- **A4 · Same canvas:** topic paste keeps a dependency outside the copy only when pasting
  back into the canvas and open document it came from (the source zone paste uses, D197).

### Approach

- **Scopes (D227, D231):** `HeadlessExport.Scope` (canvas, branch, zone, a page per
  zone) sets up the export sheet's `ExportState` and calls the controller's `exportData`;
  `HeadlessExport.zoneFiles` calls `zoneFiles`. In NexusAgent, `ExportScope.parse` reads
  `branch` / `zone` / `zones` for both the CLI and the tool, with the formats each scope
  works for (`CLIFormat.exportsBranch`, `exportsZone`).
- **Several zones (D228):** `CanvasController.zoneGroup` holds the zones selected with the
  selected one; `selectedZones` is what copy, cut, duplicate, delete and drag act on.
  `toggleZone` (⇧/⌘-click), `selectZones`, and Select All Zones (`select.allZones`, from
  the command registry, so the Edit menu and ⌘K pick it up).
- **Callouts (D229):** `Canvas.fragment` collects callouts hosted by anything in the copy
  (`callouts(on:)`, following callouts on bubbles); `graft` and `pasteZones` give their
  bubbles new ids (`mapCallouts`), and `copyElements` adds the callouts.
- **Source (D230):** topic copy writes `org.opennexus.fragment.source`; `graft` and `paste`
  take `sameCanvas` (default false), which the controller sets from the pasteboard.

### Built

- **NexusCanvas:** `HeadlessExport.Scope`, `data(…scope:)`, `zoneFiles`; the zone group on
  `CanvasController` (`selectedZones`, `toggleZone`, `selectZones`, `selectAllZones`,
  `moveZones`, `copyZones`, `removeZonesWithContents`), group-aware `deleteElement` and
  `duplicateZone`; the canvas view's ⇧/⌘-click, group drag and selected drawing
  (`ElementRenderer.selectedZones`). The empty-canvas menu's Paste (M26,
  `paste(at:)`) also passes the pasteboard's source and selects every pasted zone.
- **NexusAgent:** `ExportScope`, `CLIFormat.exportsBranch`, `exportsZone`, `names`,
  `export(…scope:)`, `zoneFiles`; `nexus export --branch / --zone / --zones` and help; the
  MCP `export` tool's `branch`, `zone` and `zones`.
- **NexusCore:** callouts in `fragment`, `graft`, `pasteZones` and `copyElements`;
  `graft(…sameCanvas:)` and `paste(…sameCanvas:)`.
- **NexusKeys:** `select.allZones` ("Select All Zones", Edit menu).
- New strings: Cut Zones, Paste Zones, Duplicate Zones, Move Zones, Select All Zones.

### Known gaps

- **Rubber-band selection doesn't select zones** (see A2 and D228).
- **Only the clicked zone takes Arrange and the Format panel** when several are selected:
  Bring to Front, Send to Back and the panel's zone section act on the selected element.
- **VoiceOver** reads the selected zone, not the group; there's no rotor action to add a
  zone to the selection (Select All Zones is the keyboard route).
- **Duplicate Branch (⌘D on a topic) still doesn't copy callouts:** it copies nodes in
  place (`CanvasEditor.duplicate`), not through `graft`.
- **Right-clicking one of several selected zones selects just that one** before its menu
  opens (`prepareContextMenu` selects the element), so the zone menu's Copy, Cut and
  Duplicate Zone (M26) act on one zone; ⌘C, ⌘X and ⌘D act on all. Keeping the group there,
  as a right-click on a selected topic keeps a multi-selection, belongs with the
  context-menu work (`CanvasMenu.swift`). **Fixed 2026-10-22 when merging M26 and M27:
  a zone in the selected group keeps the group (D228).**
