# M37 · Release packaging

## Plan

**Goal:** a release of OpenNexus to download and install on other Macs for everyday use
and testing: a Developer ID–signed app in a DMG, notarized when credentials are set up,
built by one script from a clean checkout of `main`. Direct download, not the Mac App
Store.

**Accept when:**
- **A1 · One command:** `App/tools/release.sh` archives a Release build, signs it with the
  Developer ID Application certificate, and writes `dist/OpenNexus-<version>.dmg` and its
  SHA-256.
- **A2 · Checked:** the script refuses a release where the app, any extension or the
  `nexus` helper lacks the Developer ID signature, the hardened runtime or a secure
  timestamp, or carries the `get-task-allow` debugging entitlement.
- **A3 · Notarized when possible:** with a notarytool keychain profile, the app and the DMG
  are notarized and stapled, and Gatekeeper accepts both. Without one, the DMG is still
  signed and the script says what the first launch needs.
- **A4 · Documented:** README › Install and Make a release; Handoff README §11 lists M11
  onward.
- **A5 · Verified:** the full test suite, lint and the app build pass on the merged `main`,
  and the release app launches.

### Known gaps

- **Not notarized until a profile is stored** (A3). Until then, each Mac needs Control-click › Open, or Privacy & Security › Open Anyway, the first time.
- **No in-app updates.** The app has no network entitlement (D150); a new version is a new DMG.
- **Apple silicon and macOS 27 only.** That's the deployment target; macOS 27 doesn't run on Intel Macs.
