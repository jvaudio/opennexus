# Original design request

I am going to be creating an open source MacOS 27 app that mimics the functionality of Xmind - seeking to capture the ease of creation and editing of diagrams that they do so well. The app will be called OpenNexus and I want it to be very modern, using awesome animation and transitions and other cool effects to make it feel lively. I want the canvas and nodes to be modern and beautiful. The user should be able to select multiple built-in themes and be able to create their own.

Please read the app's feature and functionality brief below and create a detailed design capturing all of the features and functionality of the app.

## Follow-up request (Xmind user-guide review)

Review all content on https://xmind.com/user-guide and its linked articles in depth, then enhance existing similar functionality or add the functionality where it serves OpenNexus goals. Design all settings screens and styling options, and include at least 6 modern node styles similar to what Xmind offers.
