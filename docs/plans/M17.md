# M17 · Canvas context menus

## Plan

**Goal (Xmind parity review; closes the M13 gap "the canvas has no context menu for
topics or other elements yet"):** right-click and Control-click menus on topics,
relationships, boundaries, summaries, callouts, images and empty canvas, as Xmind has,
built from the command registry so titles and key equivalents stay in sync.

**Accept when:**
- Every element kind has a menu: topic, multi-selection, relationship, boundary,
  summary, callout, zone, image, legend and empty canvas.
- A menu shows only what can run on the selection, as ⌘K does, and right-clicking an
  unselected topic selects it first.
- Every item is a registry command or an existing action, and running it from the menu
  does exactly what the command does from the keyboard (undo, toasts, tour coach).
- VoiceOver reaches the same actions: Show Menu, and custom actions where they weren't
  already.

### Menus

- **Topic:** Add Child Topic, Add Sibling After and Before, Add Parent Topic · Edit
  Topic, Insert ▸ (Note, Hyperlink…, Image…, Label, Markers…, Sticker… · Comment…,
  Task…, To-Do · Callout, Boundary, Summary, Relationship) · Cut, Copy, Paste, Duplicate
  Branch · Copy Style, Paste Style, Reset Style, Format Panel, Structure ▸ (the nine
  structures by name, ⌥⌘1–9, the current one checked) · Fold / Unfold Branch, Focus on
  Branch (which drills into a DFD process) · Export Branch ▸ (PNG, SVG, Markdown · Print
  Branch…, New Canvas from Topic) · Delete, Delete, Keep Children.
- **Multi-selection:** Cut, Copy · Label, Markers…, To-Do, Boundary, Summary · Paste
  Style, Reset Style, Format Panel · Delete (D177).
- **Relationship, boundary, summary, callout:** Edit Label, Edit Title or Edit Text ·
  Format Panel, Reset Style · Delete. **Zone** adds Collapse or Expand Zone, Bring to
  Front and Send to Back, then Export Zone… and Print Zone… (the D156 items).
- **Image** (right-click the picture on a topic): Replace Image…, Remove Image · Remove
  Image Background, Make a Sticker….
- **Legend:** Edit Legend…, Legend (hides it).
- **Empty canvas:** Paste, Add Floating Topic (where the menu opened), Zone · Select All
  Topics, Fit Map to Window · Export…, Print….

### How

- **Model** (`CanvasMenu.swift`): `CanvasMenuTarget` says what was clicked;
  `CanvasController.contextMenu(for:)` returns `CanvasMenuEntry` items, submenus and
  separators; `MenuBuilder` holds the per-selection rules (D175). A
  `CanvasMenuAction` is a registry command, or one of five existing actions (D174).
- **View** (`CanvasView.menu(for:)`): hit-tests legend, topic (callout topics and images
  first), then elements, then empty canvas; `prepareContextMenu` selects (D176); the
  entries become an `NSMenu`. Commands go through `performRegistryCommand`, so window
  commands continue up the responder chain; other items through `performMenuAction`.
  Right-click without a drag (when right-drag pans), plain right-click (AppKit's default)
  and Control-click all open it.
- **Element-aware commands** (D178): `.delete` and `.resetStyle` act on a selected
  element, so the menu, the menu bar, the Delete key and ⌥⌘R agree.
- **VoiceOver** (D179): `accessibilityPerformShowMenu` on topics, relationships,
  boundaries, zones, the legend and the canvas; custom actions from the same entries.

### Known gaps

- **Paste on empty canvas pastes under the selected topic,** as ⌘V does, not as a
  floating topic at the pointer.
- **Zone on empty canvas** wraps the selected floating topics or goes below the map, as
  ⌥⌘Z does; it isn't placed at the pointer.
- **Format Panel toggles,** as ⌘I does: it shows a checkmark when the panel is open and
  closes it if chosen again.
- **No menu in the outline or the Gantt view;** those keep their own keyboard paths.
- **The Format panel's structure picker** lists names in a different order from
  `structureCycle`, so the name it shows can differ from the structure it applies. Found
  while naming the Structure submenu; not changed here. **Fixed 2026-10-22 (D216).**
