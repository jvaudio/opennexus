# OpenNexus brand: Aperture

**Aperture** is a ring-shaped node left open on the right, with two branches leaving the centre through the gap. It was chosen on 2026-10-24.

- **The ring** is the O of "Open".
- **The branches** are one idea becoming a network, the "Nexus".
- **The three colours** are the canvas states:
  - Iris: Select and Edit
  - Amber: Connect
  - Aurora: on-device AI

The design board `reference/brand-board.png` (artboard *01 · Brand*) is the visual spec. This file is the numeric spec. Every asset in this kit was generated from the geometry below by `tools/gen.py`.

## 1. Geometry: 64-unit grid

| Part | Definition |
| --- | --- |
| Ring | Centre (26, 32), radius 14, stroke 5 × b, round caps. Arc from angle −g to +g the long way round, so the gap faces right. |
| Gap half-angle g | 45° + 12° × (b − 1) |
| Upper branch | `M26 32 C36 32 40 22 50 19`, stroke 3.4 × b, round caps |
| Lower branch | `M26 32 C36 32 40 42 50 45`, stroke 3.4 × b, round caps |
| Upper end node | Circle at (51, 18.6), r = 5 × s |
| Lower end node | Circle at (51, 45.4), r = 5 × s |
| Root node | Circle at (26, 32), r = 6.2 × s. Drawn last, on top. |
| Size factor s | 1 + 0.45 × (b − 1) |

**Draw order (back to front):** ring, upper branch, lower branch, upper node, lower node, root.

**Optical size boost `b`:** the mark gets bolder as it gets smaller.

| Rendered size | b | Ring stroke | Gap ± | Ring end points |
| --- | --- | --- | --- | --- |
| ≥ 128 px (default) | 1.0 | 5 | 45° | (35.90, 22.10) / (35.90, 41.90) |
| App icon | 1.1 | 5.5 | 46.2° | (35.69, 21.90) / (35.69, 42.10) |
| ≤ 32 px | 1.5 | 7.5 | 51° | (34.81, 21.12) / (34.81, 42.88) |
| Menu bar (18 pt) | 1.7 | 8.5 | 53.4° | (34.35, 20.76) / (34.35, 43.24) |
| ≤ 16 px | 1.9 | 9.5 | 55.8° | (33.87, 20.42) / (33.87, 43.58) |

**Bounds and clear space:**

- At b = 1 the mark occupies x 9.5–56, y 13.6–50.4. The masters use viewBox `8 8 50 50`.
- Clear space is r = 14 units on every side.
- Minimum sizes: mark 16 px, horizontal lockup 96 px wide.

## 3. Wordmark and lockups

- **Font:** "Open" is Geist 500 and "Nexus" is Geist 700, both tracked −3%.
- **In the kit:** the wordmark is outlined to paths, so no font is needed to display it.
- **In app UI:** use the asset, not live text. In running prose, plain "OpenNexus" in the system font is fine.
- **Horizontal lockup:** the mark is 1.5 × the wordmark font size. The gap equals 0.22 × the mark height. The wordmark's cap height is centred on the mark.
- **Stacked lockup:** the mark sits above the wordmark, both centred.

## 4. App icon (macOS 27)

### Icon Composer layers

These are 1024 × 1024, full bleed, and in `icon/icon-composer-layers/`. Icon Composer applies the shape mask, Liquid Glass and the system appearances.

| Layer | File | Content | Suggested Icon Composer settings |
| --- | --- | --- | --- |
| Background | `0-background.svg` | Iris gradient #6E67F6 → #4C43DB | Fill. Dark appearance: #2A2B33 → #121317. |
| 1 | `1-ring.svg` | White ring | Glass on, specular on |
| 2 | `2-branches.svg` | Aurora and Amber branches with their end nodes | Glass on |
| 3 | `3-root.svg` | White root node | Topmost, soft shadow |

The mark spans 78/112 of the tile width: 713 px of 1024, centred.

### Appearances

- **Default:** Iris tile with a white ring.
- **Dark:** graphite tile with the dark palette.
- **Tinted and Clear:** generated by the system from the layers. Check that the white ring and root stay legible.

### Fallbacks

- `xcode/AppIcon.appiconset`: pre-shaped PNGs on the Big Sur icon grid (824 squircle on a 1024 canvas, with shadow). The 16 px and 32 px sizes use the optical-size variants.
- `macos/AppIcon.iconset`: the same PNGs, for `iconutil -c icns`.

## 6. Don'ts

- Don't drop the branches. The bare ring reads as a power or refresh symbol.
- Don't rotate, mirror or close the gap. It always faces right.
- Don't swap the branch colours or add nodes.
- Don't put the colour mark on Iris or on busy imagery. Use the icon tile or the mono mark there.
- Don't set the wordmark in a single weight.
- Don't add outlines, gradients or shadows to the mark itself. The app icon's glass is applied by the system.

## 7. Regenerating

Run `python3 tools/gen.py <out> <Geist-variable.woff2>`, then `node tools/raster.js <out>`.

- `gen.py` needs `fonttools`, `brotli` and `uharfbuzz`.
- `raster.js` needs Playwright with Chromium.
- Change geometry or colour only in `tools/gen.py`, then regenerate. Never hand-edit individual assets.
