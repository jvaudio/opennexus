# M3 · Elements and Connect (F2)

## Plan

**Goal:** Connect mode (hint assignment, text filter, create-new, labelling);
relationships with every line shape and end cap; boundaries (with meaning and trust
level), summaries, callouts and notes; links and backlinks, markers, stickers, labels,
to-do progress and audio notes; zones and floating topics with smart guides and z-order;
plus the direct manipulation carried from M1 (drag to reparent, rubber-band selection)
and rich text inside topics carried from M2.

### Model (NexusCore)

- `Relationship` gains caps (11 each end), dash, width, colour (`source` or hex), label
  position and style, technical type, control-point offset.
- New element types stored on the canvas: `Boundary` (wraps topics' branches; 9 shapes,
  meaning group / zone / VPC / subnet / trust, trust level, tint, title position),
  `Summary` (parent + sibling range + summary topic, bracket style), `Callout` (host
  topic + callout topic, shape, pointer side), `Zone` (frame, title, auto-resize,
  collapsed, frame style, z-order, member floating topics).
- Summary topics and callout topics are real nodes (`kind` summary / callout) referenced
  from their element, so they edit, style and undo like any topic. Validation treats
  them as tree tops.
- `Node` gains `sticker`, `image`, `attachments`, `audio`, and `marks` (rich-text runs:
  bold, italic, underline, strikethrough, link over character ranges). Links are a URL,
  a file / folder URL, or `nexus:topic/<canvas>/<node>`; backlinks are derived.
- Selection gains an optional element (relationship, boundary, summary, zone).

### Behaviour

- Connect mode (⇧⌘L / ✦C): candidates sorted nearest-first get hints A S D F G H J K L
  Q W E R … then two-letter hints. Typed letters that match or prefix a hint narrow to
  hints; anything else filters by topic text. ↑↓←→ move the highlight. ↩ draws the edge
  and opens its label in Edit. No match + ↩ offers "Create new node". Esc changes nothing.
- ⇧⌘B boundary around the selection's branches; ⇧⌘] summary over a sibling range;
  ⇧⌘C callout; ⇧⌘N note sheet; ⇧⌘K link sheet (web, topic, file, folder); ⇧⌘I image;
  ⇧⌘T labels (comma separated, autocomplete); ⇧⌘M marker picker; ⌥⌘Z zone; ⌥⌘] / ⌥⌘[
  z-order; ⌘[ fly back after following a topic link.
- Mouse: drag a topic onto another (halo = child, line = before / after), ⌥-drag
  duplicates, ⇧-drag detaches to floating; drag a floating topic near a branch to attach;
  drag floating topics and zones freely with smart guides; rubber-band on empty canvas;
  click relationships, boundaries, summaries and zones to select them.

### Rendering (NexusCanvas)

Element layers below or above nodes as appropriate: zones (bottom), boundaries, branch
lines, summaries (brackets), relationships (curve + caps + label chip that avoids nodes),
nodes, callout pointers. Node decorations: label pills, indicators (note, link, file,
audio, AI), stickers, images, to-do progress ring, pinned metadata. Connect overlays: dim,
hint chips (40 ms stagger), amber rings, dashed preview, "Connect to" field.

### Tests

- Connect: hint path and text-filter path through real key events; Esc leaves the
  model byte-identical; create-new; label editing; hint assignment is nearest-first and
  unique.
- Every element command is one undo step; deleting a topic removes elements that
  depended on it; JSON round trip with unknown keys; schema updated.
- Geometry: boundary encloses its branches, summary bracket spans its range, callout
  stays attached through reflow, zone moves its members.
- Drag: reparent, before/after, detach, attach; rich text runs survive edit and save.

Built:
- Connect mode (⇧⌘L): prefix-free hints assigned nearest-first with a 40 ms stagger, hint
  then prefix then text filtering, ↑↓ to move the highlight, create-new when nothing
  matches, a dashed preview, then the label opens in Edit.
- Relationships: curved, straight, elbow and zigzag lines; 11 caps at each end with swap;
  dash, width and colour (theme, source or hex); label position and style; technical type.
  Curves bow away from topics they would cross.
- Boundaries (9 shapes; meaning group, zone, VPC, subnet or trust; trust level; tint;
  hatch). Branches inside a boundary reserve its padding and title band in the layout.
- Summaries: the bracket (curly, square, round or line) spans the range and sits outside
  any enclosing boundary. Each summary owns a real topic that can have children.
- Callouts: a bubble with a pointer that stays with its host through reflow.
- Zones (⌥⌘Z): title, auto-size, collapse with hidden count, frame styles, z-order, members
  that move with the zone, and adoption on drop.
- Enrichments:
  - Notes, links (web, topic, file, folder) with backlinks and fly-back (⌘[).
  - Markers in groups (picking from the same group replaces), emoji stickers, labels with
    autocomplete and usage counts.
  - Images and attachments (drag a file onto a topic), stored by content hash.
  - Audio notes recorded to m4a.
  - To-do progress rings.
- Rich text in topics: ⌘B, ⌘I and ⌘K on a selection, stored as `marks`. Balanced wrapping
  stops long topics ending on a lone word.
- Mouse:
  - Drag onto a topic (child) or beside it (before / after); ⌥ duplicates, ⇧ detaches.
  - Smart guides with spacing labels; "Drop to attach under X" hint.
  - Plain drag on empty canvas rubber-bands; ⌥-drag pans.
  - Click to select elements; double-click to edit.
- Format panel FMT-2: Relationship, Boundary, Callout, Summary and Zone sections swap in
  for the selected element, each with Reset style and Delete.
- Schema: added boundaries, summaries, callouts and zones, plus every new node and
  relationship key. Both copies stay identical and canonical.
- App: added the sandboxed microphone entitlement and its usage string; still no network
  entitlement. ⌘I steps aside for Italic while you edit text.

Defects found during M3 review and fixed:
- The extended undo property test found that removing a callout or summary dropped its
  topic but not that topic's children or relationships. Summary and callout topics could
  also be re-parented. Topics owned by an element now refuse to move.
- Main topics are already semibold, so ⌘B would toggle bold *off*, which a mark can't
  store. It now beeps instead (see D42).
- In the snapshots, the VPC boundary covered a neighbouring topic, the summary bracket sat
  on the boundary edge, and relationship curves ran through the central topic.
- Editing a relationship label blanked its source topic and didn't grow the label chip.
