# M8 · Settings, Home and onboarding

## Plan

**Goal (README §11, §10 Settings inventory; brief "First-run experience and tutorial"):**
- All 10 Settings panes, with search.
- The Home window: recents, a template shelf filtered by role, and the new-document type
  picker.
- Welcome, the role picker, and the tutorial (F5, 6 lessons and a finish card) with the
  keycap coach.
- Tips, plus the toast shown the third time a user reaches for the mouse.

**Accept when:**
- The screens match artboards 08, 14–16, 29, 31 and 35–42.
- Every setting persists and takes effect live.

### Settings

- **A declarative schema** (`SettingsSchema`, mirroring the sources' `sec()` and
  `T S G R B K I` helpers). Each pane has sections, and each section has rows.
- **Row kinds:** toggle, segmented, menu, stepper or number, button, keycaps, info, and
  custom preview cards.
- **Every row has a key, a default, a title, an optional detail line, and search
  keywords.** The window is generated from the schema, so search (the sidebar field, or
  ⌘F) finds every row, jumps to its pane and highlights it.
- **`Preferences`:** an observable store over `UserDefaults`, typed accessors, and change
  notifications. Views and controllers read it live, so there's no restart (except
  Language, as the artboard says).
- **The panes and what each row drives:**
  - **General:**
    - Appearance (`NSApp.appearance`).
    - Language (`AppleLanguages`; restart).
    - At launch (last documents, Home or a new document).
    - Open documents in tabs or windows (`tabbingMode`).
    - Restore windows.
    - Spelling, autocorrect and smart quotes (the node editor).
    - Units (export, print and layout fields).
    - Updates: locked, see below.
    - Help & tips: progressive tips, hint keycaps, the ⌘ cheat sheet, Replay tour,
      What's new.
    - The About card.
  - **Editing:**
    - Typing on a selected node: replaces, appends, or Space edits keeping the text.
    - New topics start with a placeholder or empty, and the placeholder text by type.
    - UML members auto-format; the slash menu at the start of an empty node.
    - New canvases use auto or free layout.
    - Alignment guides, snap to grid, grid size, snap distance.
    - Animate reflow.
    - Floating toolbar (new, minimal) and Add Topic + buttons (new).
    - Double-click on empty canvas; scroll wheel pans or zooms; right-drag pans;
      dragging a node off its branch floats it.
    - New documents: use the last skeleton, default structure, default zoom, start in
      Edit mode.
  - **Appearance:**
    - The default look for new documents: theme grid, node style, colour theme, and
      the live preview.
    - Follow system light/dark (paired themes).
    - Diagram font and CJK font.
    - Canvas background (plain, dots or lines).
    - Minimap (new): while panning, always, or never.
    - Minimum text size at 100%; adapt text colour.
    - Animations full, reduced or off; glow trail, done sparkle, depth parallax, flow
      dots.
    - ZEN appearance, Today timer and counts.
    - Liquid Glass chrome; toolbar icons and text.
  - **Files & Backup:**
    - Autosave (always on); keep versions; ask before closing unsaved new documents.
    - Default location.
    - Save as package or single JSON (a second document type); JSON pretty or compact.
    - Embed images up to N MB; optimise images on import (HEIC → WebP is not
      available, so HEIC → JPEG, with location metadata stripped).
    - Snapshot interval and retention; storage used; Open Recovery…; Delete all.
    - Store passwords in the Keychain; lock encrypted documents after idle; Touch ID
      to open (LocalAuthentication).
    - The recovery list card.
  - **AI:** the M6 pane, moved into the schema.
  - **Shortcuts (artboard 08):**
    - Profiles (OpenNexus, Hyper-first, Vim-style, Outliner) and the Hyper key card.
    - Searchable table by scope, with standard and Hyper chords.
    - Click a chord to record it. Conflicts show Swap, Reassign or Scope to <scope>.
    - Import profile…, Export JSON, Restore Defaults.
    - Overrides persist as JSON and apply live to the canvas and the menu bar.
  - **Export:**
    - The six image frames (None, Soft shadow, Window, Gradient mat, Paper, Dark mat)
      with previews; aspect; mat colour.
    - Scale, background, padding and split defaults; colour profile (sRGB or
      Display P3).
    - PDF content, page size, fit and appendix defaults; clickable topic links.
    - Markdown and Mermaid/PlantUML defaults; JSON.
    - Data masking (ask, always or never); strip AI provenance.
    - Watermark fixed at **Never**.
    - The export sheet opens with these defaults until a format has remembered
      settings.
  - **Integrations:**
    - Quick Capture, macOS (Shortcuts, Services, Share, Safari clipper, Spotlight),
      code links, MCP and CLI rows, and the agent card.
    - The values persist now; the features they switch are built in M9.
  - **Privacy & Data:**
    - The network activity log (it reads "0 requests", because OpenNexus makes none).
    - Diagnostics: local only.
    - Link previews: locked.
    - AI data: let AI read notes; keep chats in the document, on this Mac, or not at
      all; remove chats on export; clear all.
    - Data masking kinds, custom regex patterns, the replacement glyph, and a live
      preview. These drive the M6 Masker and export masking.
  - **Accessibility:**
    - Follow system text size in chrome; minimum canvas text; High Contrast with
      Increase Contrast.
    - Patterns as well as colour; selection ring width.
    - Reduce motion and transparency (system, on or off); pause ghost shimmer.
    - VoiceOver announcements; how edges are read.
    - Full keyboard access; sticky Hyper; cheat sheet delay; keycap coach size.
    - The VoiceOver preview card.
- **Locked by design:** "Check for updates", "Install updates", the update channel,
  "Fetch link previews", "Share usage statistics" and "Send" crash reports would need the
  network.
  - They're shown as on the artboards, off and disabled, with the reason: OpenNexus v1
    makes no network requests.
  - The update row reads "Updates come from where you installed OpenNexus".

### Home, Welcome, roles and the tour

- **Home window (artboard 16):**
  - Sidebar: Home, Recents, Templates, Inbox map, Locations (the folders of recent
    documents), Saved filters (from recent documents), and an AI status line.
  - "Good morning/afternoon/evening"; search across maps and nodes in recent documents.
  - Import…; New cards for eight types (⌘N is a blank mind map; ⇧⌘N opens Home on the
    type picker).
  - Recents with thumbnails rendered from each package.
  - Templates by role (Engineering, Architecture, Security, Planning, Learning), five
    real templates each.
  - The empty state after the tour.
  - Opened at launch (per General › At launch) or with ⇧⌘H.
- **Welcome (14):** a dark glass card over a slowly self-building map, with Start the
  4-minute tour (↩), Skip to a blank map, and Import from Xmind…. Shown on first launch;
  replayable from Settings › General.
- **Role picker (15):**
  - Step 2 of 9; four cards; 1–4 or ←→ then ↩; Skip tour or Continue as <role>.
  - The role is stored. It sets the tour example and the Home template shelf, and can be
    changed in Settings › General.
- **Tutorial (31):**
  - A real document built in the canvas. A `TourController` watches the canvas
    controller's keys and patches.
  - Lessons:
    1. Type.
    2. ⇥, ↩, ⇧↩ and ⌘↩.
    3. Arrows, then ⌥⌘↑↓ and ⌘/.
    4. ⇧⌘L, a hint letter, then naming the edge.
    5. ⌥⌘T converts directly to the role's type (flowchart, architecture, DFD or
       timeline).
    6. ⌥Space and ⌃↩. If Apple Intelligence is off, lesson 6 uses scripted ideas.
  - Then a finish card with the elapsed time and the keys learned.
  - The keycap coach: prompt, pressed, success, wrong key (it shows what the key did,
    offers undo, and repeats the prompt), and chords. It floats 16 pt beside the
    selection, never over the editor.
  - Progress dots. Click away and the tour pauses in a corner pill with Resume. Every
    step is skippable. The tutorial map stays as the user's first document.
- **Tips:**
  - Each command the user runs with the mouse (menu, toolbar or context menu) is
    counted. The third time, a quiet toast says "Faster: <keys> <does> · Don't show
    tips".
  - Empty canvases show three faint hint keycaps (⇥ · ↩ · /) that fade after the first
    keystroke.
  - On a .xmind import, the "Your keys already work here" card shows beside the import
    report.

Built:
- **Settings:** a declarative schema (`SettingsSchema`, 10 panes, 150+ rows) rendered by one `SettingsView`, with search across every pane (⌘F), the section cards from the artboards (themes, look preview, frames, mat colour, agent, network log, masking preview, VoiceOver preview, recovery list, About) and a Shortcuts pane with profiles, the Hyper card, a recorder and conflict resolution (Swap / Reassign / Scope to …), and JSON import and export.
- **Preferences** (`NexusCanvas`): an injectable `@Observable` store with schema defaults; the canvas observes it and re-applies only what changed.
- **KeyCustomization** (`NexusKeys`): per-command chords and scopes over the standard registry, applied live to the canvas and the menu bar.
- **Home:** recents with type thumbnails and details, locations and saved filters from recent documents, search across titles and topic text, New cards with ⇧⌘N choose-type mode (1–7), the More… types, a role-filtered template shelf (25 templates in five categories), the Inbox and the tutorial-map empty state.
- **Onboarding:** Welcome (self-building map), the role picker (1–4, arrows, ↩), and the tour: six lessons and a finish card in a real document, following real commands and edits, with the keycap coach (prompt, success, wrong key with undo hint), pause to a corner pill when the window loses focus, skip, and a role-specific ⌥⌘T conversion. Without Apple Intelligence, lesson 6 uses scripted ideas.
- **Tips:** the third mouse use of a command shows its key; any key press clears it. Hint keycaps on empty canvases.
- **Mouse aids:** the floating toolbar and Add Topic + buttons; minimap.
- **Hyper key:** Right Option held (no permission needed); Caps Lock arms a sticky Hyper; a tap alone is Esc.
- **App:** Settings window, Home window (⇧⌘H, or at launch), first-run flow, single-JSON document type, AI chat placement, idle lock and Touch ID unlock, snapshot interval, retention and pruning, window and tabbing preferences, What's New.
- **Export:** image frames (soft shadow, window, gradient mat, paper, dark mat), aspect padding, mat colour, Display P3, clickable links in PDFs, masking (ask / always / never), stripping AI provenance and chats, JSON with embedded images.

Defects found during M8 review and fixed:
- The tour overlays were constrained before being added to the canvas host, which crashed every document window. Found by the first harness test.
- Key-to-caret had grown to 43 ms (budget 16 ms). The VoiceOver description recomputed every topic's depth by rebuilding the parent map each time (O(n²) on each selection change), and the M8 CJK font cascade made every font lookup build a new descriptor. Depths now come from one walk, and fonts are cached per face: 11 ms median, 1k reflow 27 ms.
- Per-format export memory read and wrote `UserDefaults.standard` rather than the injected preferences, so tests and the live store leaked into each other.
- Golden tests depended on the Mac's light or dark appearance once Follow system was on by default; the harness now renders themes as named.
- Visual review: the Welcome headline and kicker, role cards, Home and Settings type were 10–25% too large; Home's More… was a bare pill (a borderless `Menu` drops a custom label) and is now the eighth card with a popover; Settings rows were too tall; Recovery and VoiceOver were in the wrong columns; Grid size, Snap distance, Padding and cheat-sheet delay are sliders; the network log card is dark.

Tests: 277 test functions across 8 targets, all passing (`swift test`; lint clean). New this milestone:
- `SettingsSchemaTests` (5): pane order and tints, unique keys and typed defaults, search finds every row, network rows locked off, persistence and change notifications.
- `KeyCustomizationTests` (2): swap, reassign, scope, JSON round trip; Hyper bindings survive recording.
- `TemplateTests`, `HomeModelTests`.
- `PreferenceEffectTests` (13), as above.
- `TourTests` (4): all six lessons with real keys, wrong-key coaching, pause / resume / skip / end, and every role's conversion.
- Format: document JSON with embedded assets; snapshot usage, most-recent, keep-for pruning and delete-all.
- Performance: key→caret 11.3 ms median (budget 16), 1k reflow 27.5 ms (budget 50).

Not covered by automated tests (app-level code the harness doesn't host; checked by building and reading): saving and reading single-JSON documents, the snapshot timer, the idle lock and Touch ID, the menu bar rebuild after a shortcut change, minimap visibility and the cheat-sheet delay timing.

Known gaps, carried forward:
- Integrations rows (Quick Capture, Services, Share, Spotlight, MCP, the CLI) persist their values but act in M9; the pane says so.
- Accessibility › Follow system text size in chrome and Full keyboard access to panels are stored but applied in M10.
- Settings › Export has no Map Shot folder picker yet (Map Shot asks on first use, D100).
