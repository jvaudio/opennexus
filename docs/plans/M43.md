# M43 · Interactive HTML export

Phase 1 of `collaboration-and-reach.md`: one self-contained `.html` file that opens offline
in any modern browser, makes no network requests, and lets the reader pan, zoom, search,
browse the outline and open each topic's details. The viewer built here is reused by share
links (M44), the web viewer (M47) and the Obsidian plugin (M49).

## Plan

### Swift (NexusCanvas, NexusFormat, NexusAgent, the app)

- **SVG parity and speed** (`SVGExporter.swift`). Draw what the canvas layers draw and the
  SVG left out: structure decor (`scene.decor`: braces, matrix and tree-table cells,
  swimlane bands, lifelines, activation bars), callouts, topic images and stickers,
  pinned fields, technical decor (icon, kicker, caption, lead text, badge, accent, tint)
  and the +N badge. New `Options`: `idPrefix` (several SVGs share one page), `images`
  (embed as `data:` or reference an asset name), `fields` (custom-field attributes).
  Outlined text writes each glyph once as a `<symbol>` and places it with `<use>`; numbers
  are written without `String(format:)` or regexes.
- **Bundle** (`ViewerBundle.swift`). `ViewerBundleBuilder.build(model, options)` returns a
  `JSONValue` matching `schema/viewer.schema.json` (version 1): per canvas the title, type,
  theme colours, two layouts (`saved`, `expanded`: an SVG plus an index of topic frames,
  text frames, parents, depths, folds, hidden counts and badge rectangles), the outline,
  per-topic details (spoken label from `Spoken.describe`, note, comments, link,
  attachments, task line, labels, markers, type), the legend and, for threat models, the
  threat table. Assets are keyed by name. Options: scope (document, canvas, branch, zone),
  notes, comments, attachments, layouts (both or as saved), theme override; masking and
  Strip AI provenance come from the export model as for every format. The viewer's
  chrome strings come from `Loc`, so the page follows the app's language.
- **HTML** (`HTMLExporter.swift`). One file: inline CSS, inline script, the bundle in
  `<script type="application/json">` with `</` and `<!--` escaped, and a CSP meta tag:
  `default-src 'none'`, the script and the style by SHA-256 hash, images from `data:` and
  `blob:` only. The built viewer is a resource, `Sources/NexusCanvas/Viewer/`.
- **Export** (`CanvasController+Files.swift`, `FileViews.swift`). `ExportFormat.html` in the
  Document group, "Interactive HTML": Scope, Include notes / comments / attachments (with
  the attachments' size), Layouts; the existing masking toggle and theme override.
  New command `file.exportHTML`, Export as Interactive HTML… (File menu, palette).
- **CLI and MCP** (`CLIFormat`, `NexusCLI`, `MapTools`). `nexus export --to html` with
  `--canvas`, `--branch`, `--zone`, `--no-notes`, `--no-comments`, `--attachments`,
  `--layouts saved|both`; the MCP `export` tool accepts `html`. Both go through
  `HeadlessExport` → `exportData`, the sheet's own path.
- **Viewer copy** (`ViewerCopy.swift`, `NexusDocument`, `MapFiles.write`). Settings › Files
  & Backup: "Save a viewer copy for browsers and Obsidian" (`files.viewerCopy`, on) and
  "Also in single-file documents" (`files.viewerCopyJSON`, off). Packages get
  `render/viewer.json` (compact JSON, assets referenced by name, not copied); `.nexusjson`
  gets a `render` key. Never for encrypted documents. Built on the main thread at save,
  cached per document revision. `.gitignore` gains `render/`. `nexus validate` checks the
  copy against the schema.
- **Schema.** `schema/viewer.schema.json`, with its copy in `NexusFormat/Resources`.

### Web (`web/`, a new npm workspace)

- `web/viewer-core`: strict TypeScript, no framework, built by esbuild into
  `opennexus-viewer.js` and `opennexus-viewer.css`. Modules: `bundle` (types and checks),
  `sanitize` (allow-list for SVG and links), `camera` (pan, zoom, fly-to with Reduce
  Motion), `outline` (ARIA tree), `details`, `search` (mirrors the app's Find, including
  ICU-like whole-word boundaries), `spatial` (arrow-key navigation), `viewer` (mount,
  tabs, layouts, keyboard, print). `window.OpenNexusViewer.mount(element, bundle)` for
  later hosts; the page auto-mounts.
- Checks: `tsc --noEmit`, ESLint (typescript-eslint, strict), Vitest (jsdom), Playwright
  (Chromium, WebKit, Firefox) with axe-core. `scripts/build-viewer.sh` builds and copies
  the viewer into the Swift resources; `--check` fails when the committed copy is stale,
  and `scripts/lint.sh` runs it.
- Fixtures: a Swift test (`NEXUS_WRITE_VIEWER_FIXTURES=1`) writes `web/fixtures/`: the
  HTML export of each golden document, the app's PNG of each canvas, the expected Find
  counts, a 1,000-topic export, and branch, zone and masked exports. A normal run checks
  they're current.

### Tests

- Swift: `SVGParityTests`, `ViewerBundleTests`, `HTMLExportTests`, `ViewerCopyTests`;
  `NetworkPrivacyTests` also scans the built viewer and `web/viewer-core/src`;
  `LoaderFuzzTests` covers a garbage viewer copy; `FormatTests` the `.gitignore` line.
- Vitest: sanitiser, search counts and boundaries, spatial navigation, outline model,
  link filter.
- Playwright: opening offline in three browsers, raster match, reader features, scopes and
  a malicious bundle, timing and size, axe-core.

### Built

- **Swift.** `ViewerBundle` (the bundle, `schema/viewer.schema.json` v1), `HTMLExporter`
  (the page, CSP by hash), `ViewerCopy` (`render/viewer.json`, the `render` key);
  Interactive HTML in the export sheet's Document group with Scope, Layouts, theme, notes,
  comments and attachments (with their size), and the size line in topics;
  `file.exportHTML`; `nexus export --to html` and the MCP `export` tool's html options;
  `nexus validate` checks a viewer copy; two Files settings; `.gitignore` gains `render/`.
  The SVG export now draws everything the canvas draws (D322), and gained `idPrefix`,
  `fields`, `reuseGlyphs` and `embedImages`.
- **Web.** `web/` (npm workspaces, exact versions): `viewer-core` in strict TypeScript
  without a framework (bundle checks, sanitiser, camera, outline tree, details, search,
  spatial navigation, the viewer), built by esbuild; ESLint (strict, type-checked, with the
  network and HTML-injection APIs banned in `src/`), Vitest, Playwright with axe-core.
  `scripts/build-viewer.sh` builds and copies the viewer into `Sources/NexusCanvas/Viewer/`;
  CI runs `npm run check`.

### Changed from the plan

- **No `SVGParityTests` in Swift.** Parity is measured where it shows, in A2: the page's
  SVG rasterised by two browser engines against the app's PNG.
- **Fixtures are made by the check, not committed** (D323), so there's no staleness check
  for them; the built viewer is committed and checked.
- **Firefox isn't run on this Mac or the CI runner** (D326).
- **The bundle escapes every `<`** in the page (`<`), not only `</` and `<!--`.
- **The cache is the last document saved** (compared by value), not a revision counter.
- **TypeScript 6.0.3, not 7.0:** typescript-eslint 8.72 supports TypeScript below 6.1.
- **The outline is a flat ARIA tree** (D325), not nested groups.

### Defects found

- `CanonicalJSON.writeString` appended scalar by scalar: a megabyte SVG took most of the
  export's time. It now copies the runs between escapes.
- The SVG export left out swimlane bands, structure decor, callouts, topic images and
  stickers, pinned fields, technical decor and the +N badge (D322).
- axe-core: the +N badge was a button inside the topic's button; each outline item's name
  included its whole branch and the ▸ character; the keyboard hint failed contrast while
  fading in. All fixed (D325; the hint now shows without fading).
- The outline's narrow-window rule was inverted in CSS; the viewer now closes the outline
  when it starts narrower than 720 px.

### Known gaps

- Firefox is unverified until Playwright ships a Firefox that starts on macOS 27 (D326).
- The SVG's text is set with Core Text frames, the canvas's with AppKit string drawing:
  glyph edges differ by a pixel here and there (A2's changed pixels). The hand-drawn
  style's wobble isn't in the SVG, so a hand-drawn map draws clean in the page.
- The page's search folds case one character at a time; the app's ICU search also matches
  "ß" with "SS". Rare in practice; the Find counts match on every test query.
- The transparent text layer's font size is estimated from the text frame, so the
  browser's own Find highlight can sit slightly off the drawn text.
- Task labels such as "due tomorrow" are as of the export day.
- Attachments aren't in the page unless chosen; the viewer copy names its assets, and the
  hosts that read them from the package arrive in M47 and M49.
