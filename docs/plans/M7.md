# M7 · Files, import and export

## Plan

**Goal (README §11, brief "Import, export and file format"):**
- The export sheet (⇧⌘E) with a live preview for every format in the brief's table.
- The import list (artboard 33) and the import report.
- Pasting Markdown or indented text creates a branch.
- Map Shot (⌃⌘M), split by branch, and branch export.
- Print with tiling.
- Merge documents.
- Encryption with the Keychain.
- Recovery snapshots and Revert To.

**Accept when:**
- The sheets match artboards 30, 50 and 51 (and the import report on 33).
- Golden-file tests pass for each importer and exporter.
- A corpus of real `.xmind` files imports with a report and no crashes.
- No watermark appears anywhere.

### Architecture

- **`NexusInterchange` (new target, pure and headless):** every text and package format,
  so each one gets golden tests and the `nexus` CLI can use it later (M9).
  - `Zip`: a reader (stored and deflate, via the Compression framework) and a writer.
    The writer moves here from `SlideExporter`.
  - Exporters: Markdown (headings or bullets, notes, an optional Mermaid block), OPML,
    Mermaid (mindmap, flowchart, sequence, class; auto-chosen from the type), PlantUML,
    draw.io (positions from the layout and branch colours), JSON and YAML (the document
    in the OpenNexus schema, pretty or compact), CSV (threat table or task list), and
    Word `.docx` (an outline as headings, notes as paragraphs, and an optional diagram
    image).
  - Importers:
    - `.xmind`: Xmind Zen/2020+ `content.json`, and XMind 8 `content.xml`.
    - OPML, Markdown, indented text, Mermaid (mindmap and flowchart), PlantUML (the
      `@startmindmap` subset), draw.io (plain or deflated diagrams), FreeMind `.mm`,
      MindManager `.mmap` and MindNode (best effort), TextBundle, and Word `.docx`
      (headings and lists).
    - Each importer returns `Imported` (canvases, assets and an `ImportReport`).
  - `ImportReport`: sheets → canvases; topics, markers and notes; and a list of what was
    not converted (with counts), shown as on artboard 33.
- **Undoable document-level changes:** `Patch` gains a canvas-set change (canvases added
  or removed, and the tab order). Merging, importing into this document, translated or
  masked copies, and canvas add and delete are then one undo each, through the same
  `store.commit`.
- **Visual exports (NexusCanvas, `ImageExporter`):** the scene is rendered offscreen by
  the same layers as the canvas.
  - PNG and JPEG: scale 1–4×; background Theme, White or Transparent; padding; a theme
    override.
  - PDF: vector, one page, or tiled pages with cut marks and notes as an appendix.
  - SVG: generated from the `Scene` (shapes, branch paths, text). Text is either live
    `<text>` in the system font stack or outlined glyph paths. Optional `data-nexus-*`
    metadata.
  - Scope: canvas, selection (with the topics they need) or branch. Split by main
    branch writes `01-positioning.png`, and so on.
  - No watermark, ever: a test scans every exporter's output.
- **Sheets and overlays (NexusCanvas):**
  - Export sheet (⇧⌘E): format list (Visual / Structural / Document), live preview
    (image, or text in a code view), per-format options, the size line ("2880 × 1850 px ·
    412 KB"), and Copy / Cancel / Export…. The last-used settings are remembered per
    format.
  - Map Shot (⌃⌘M): a dimmed canvas, a draggable and resizable frame with its size
    badge, aspect presets (1:1, 4:3, 16:10, 16:9, Free), frame colour, padding, shadow,
    and Copy & Save (↩), or ⌥↩ to copy only. Saved to the folder in Settings › Export
    (the user picks it once; stored as a security-scoped bookmark).
  - Branch commands: Export branch as PNG / SVG / Markdown…, Copy branch as image (⌃⌘C),
    Print branch…; Copy as Markdown and Copy as Mermaid.
  - Print (⌘P): content (Canvas / Branch / Outline), page size and orientation, Fit page
    or Actual size, tile across pages with cut marks, background colour, notes as an
    appendix, and a title · date header. It prints the generated PDF through
    `NSPrintOperation`, and "PDF ▾" offers Save as PDF.
  - Merge (Tools › Merge…): documents (`.nexus`, `.xmind`, OPML, Markdown) as canvases or
    into this canvas, with an optional Map of Content index canvas. One undo.
  - Import (File › Import…): any supported format, as a new document; the import report
    sheet follows.
  - Paste: Markdown, indented text, OPML or Mermaid text on the clipboard becomes a
    branch under the selection, as one undo. Plain one-line text still pastes as a topic.
- **Encryption (File › Set Password…):**
  - Format: `manifest.json` keeps `format`, `schemaVersion` and an `encryption` block
    (algorithm, KDF, iterations, salt, hint). `encrypted.bin` holds AES-GCM (CryptoKit)
    over a zip of the inner package. The key is PBKDF2-SHA256 (CommonCrypto), 600 000
    iterations.
  - "Remember in Keychain" stores the password as a generic password keyed by the
    document's id.
  - Opening an encrypted document uses the Keychain, or shows an unlock sheet. Remove
    Password… returns it to plain.
  - Recovery snapshots of an encrypted document are encrypted with the same key.
- **Recovery snapshots:** every 5 minutes of editing, and on close, the document is saved
  as a snapshot in `~/Library/Application Support/OpenNexus/Snapshots/<document id>/`
  (the last 20 are kept). File › Revert To › Browse Recovery Snapshots… lists them
  (time, topics) with Restore, which is undoable. NSDocument versions keep File ›
  Revert To › Browse All Versions.

### Tests

- Golden files (`Tests/NexusInterchangeTests/Goldens`; set `REGENERATE_GOLDENS=1` to
  rewrite them):
  - every exporter on the sample maps (launch plan, DFD, sequence, threat model);
  - every importer on a fixture, compared as the canonical JSON of the result plus the
    report.
- Round trips: Markdown, OPML, Mermaid and `.nexus` JSON.
- Xmind:
  - Zen and XMind 8 fixtures (sheets, floating topics, boundaries, summaries, callouts,
    relationships, notes, markers, labels, links, images, unsupported extensions).
  - Fuzzed and truncated archives never crash.
  - The real corpus runs when `NEXUS_XMIND_CORPUS` points at a list of files. It reports
    counts only, and skips cloud placeholders (zero bytes, not downloaded).
- Zip: deflate and store round trips; a reader for files made by `/usr/bin/zip`, tested
  in-process.
- Paste: a Markdown or indented clipboard creates a branch; one undo.
- Merge: as canvases and into this canvas; Map of Content links; one undo, both ways.
- Patch canvas-set changes: add or remove canvases; undo restores the order.
- Encryption: round trip; a wrong password fails; the hint is readable without the
  password; the encrypted package contains no plaintext topic text.
- Snapshots: written, pruned to 20, restored.
- Visual exporters: PNG size by scale and padding; transparency; JPEG; PDF pages
  (tiling); SVG well-formed with metadata; split by branch file names; no watermark.
- Snapshots of the export sheet, Map Shot, print, merge and encrypt sheets, compared
  with 30, 50 and 51.

Built:
- **NexusInterchange (new target):**
  - Importers: Xmind (Zen and XMind 8: sheets, floating topics, boundaries, summaries, callouts, relationships, notes, markers, labels, links, images, attachments, folding, structures), OPML, Markdown, indented text, Mermaid (mindmap, flowchart, sequence, class), PlantUML (mind map, WBS, sequence), draw.io, FreeMind / Freeplane, MindManager, MindNode, TextBundle, Word, and `.nexus` / document JSON for merging.

  - `ImportReport` and format detection by extension or content.
- **NexusFormat:** a zip reader and writer (deflate via Foundation), package encryption (`PackageCrypto`), and recovery snapshots (`SnapshotStore`).
- **NexusCore:**
  - `Patch` canvas-set changes, so whole-canvas adds and removes and tab order are undoable.
  - Topic fragments, `graft` and `paste`, and `DocumentModel.add` (fresh canvas ids, with links rewritten).
- **Canvas:**
  - Visual exporters: PNG, JPEG, single-page PDF, SVG, split by branch, and branch scope.
  - The print layout: fit, actual size or tiled with cut marks; outline content; a notes appendix; a header.
  - The export sheet, with settings remembered per format.
  - Map Shot (keyboard: arrows nudge, ⌥-arrows resize, 1–5 pick an aspect, ↩ / ⌥↩ / Esc; mouse: drag and handles).
  - Copy, cut and paste of topics; paste of Markdown, indented text, OPML or Mermaid as a branch.

- **App:**

  - Snapshots every five minutes and on close; Restore is one undo.
  - The Map Shot folder bookmark; the tab context menu and ▾ menu; Move to New Window.

Defects found during M7 review and fixed:
- An Xmind task-progress pie was turned into a to-do checkbox, losing partial progress. It is now a progress marker.
- MindManager counted nested topics' icons twice; MindNode reported each top topic as a sheet.
- Word import turned table cells into notes; Markdown notes collected runs of blank lines.
- Binary files with unknown extensions were sniffed as text; a heading's to-do was lost in Markdown.
- Transparent exports weren't transparent: the canvas root layer painted its own background.
- An SVG fill attribute was malformed, and text positions on `<tspan>` were ignored by AppKit's SVG renderer. Text now carries its position and font on `<text>`.
- Export settings weren't remembered when you switched to another format.
- New canvases, AI translated and masked copies, and DFD drill-down levels were each two undo steps, or undoable only in the app. They now go through one `Patch`.

Tests: 246 test functions across 8 targets, all passing. New this milestone:
- `NexusInterchangeTests` (15, including 19 parameterised importer goldens, fuzzing and the gated real corpus).
- `ClipboardTests` (3); `EncryptionTests` (2).
- `FileFlowTests` (8):
  - copy, cut and paste and outline paste;
  - merge both ways;
  - canvas tab operations;
  - image scale, padding, background and scope;
  - SVG well-formedness, metadata and outlines;
  - print tiling and appendix;
  - Map Shot keys and output;
  - export settings and every format's file.
- `FileSnapshotTests`: visual review, env-gated.

Known gaps carried forward:
- **App-level flows are not automated:** unlock prompt, Keychain, print panel, save panels, Import… menu and snapshot restore. Their logic is tested; the AppKit panels were checked only by building.
- **Images or PDFs via AI** (brief, Import) are not done; there's no on-device layout-to-map model yet.
- **Settings › Export** (the Map Shot folder and default formats) is asked in place for now; the pane arrives with M8.
- **PDF map pages are high-resolution images** inside vector pages, so map text isn't selectable (D97). Outline and appendix text is.
- **Keynote export** is a .pptx that Keynote opens (D74). There's no Xmind export, which the brief doesn't list.
