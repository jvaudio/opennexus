# M0 · Foundations

## Plan

**Goal:** a buildable repo with the core model, file format, tokens and command
registry in place, all covered by tests, so M1 can put a canvas on top.

### Files and types

| Package | Files | Key types |
| --- | --- | --- |
| `NexusCore` | `JSONValue.swift`, `IDs.swift`, `Node.swift`, `Canvas.swift`, `Document.swift`, `Patch.swift`, `Editor.swift`, `UndoStack.swift`, `TreeOps.swift`, `Selection.swift` | `JSONValue` (ordered-free JSON tree), `NodeID`, `CanvasID`, `Node`, `Canvas`, `NexusDocument`, `Patch` (reversible change set), `CanvasEditor` (records before-images on first touch), `UndoStack` (coalescing), tree operations (add child / sibling / parent, delete, delete-keep-children, reorder, promote, demote, duplicate, fold) |
| `NexusFormat` | `CanonicalJSON.swift`, `NexusPackage.swift`, `Schema.swift`, `SchemaValidator.swift` | Canonical writer (sorted keys, 2-space indent, `": "`, LF, trailing newline, numbers rounded to 0.5 where they are positions), package read/write (`manifest.json`, `canvases/<id>.json`, `theme.json`, `assets/`, generated `.gitignore` for `snapshots/`), a small JSON-Schema (draft 2020-12 subset) validator |
| `NexusTheme` | `Tokens.swift`, `Color.swift`, `Contrast.swift`, `Themes.swift`, `NodeStyles.swift` | `RGBA` colour, WCAG contrast ratio, signal / neutral / motion tokens transcribed from `design-tokens.json`, theme and node-style data (filled out in M2) |
| `NexusKeys` | `KeyChord.swift`, `Command.swift`, `Registry.swift`, `DefaultCommands.swift`, `Conflicts.swift` | `KeyChord` (modifiers + key, glyph rendering incl. ✦ Hyper), `CommandDescriptor` (id, title, category, scope, default keys, hyper key), `CommandRegistry`, `KeyProfile`, conflict detection per scope |
| `schema/` | `nexus.schema.json` | Published schema for `manifest.json` and `canvases/*.json` |

Unknown keys round-trip: every model struct keeps an `extra: [String: JSONValue]`
bag that is filled with keys it does not recognise and written back unchanged.

### Tests (Swift Testing)

- **NexusCore:** do/undo symmetry for every tree op (property-style over random op
  sequences), coalescing, selection helpers.
- **NexusFormat:** byte-identical round trip of sample packages, unknown-key
  passthrough, schema validation of samples (and rejection of broken ones),
  position rounding.
- **NexusTheme:** contrast-ratio maths against WCAG reference values; tokens parse.
- **NexusKeys:** no two commands in one scope share a chord in any profile; glyph
  rendering.

### CI

`.github/workflows/ci.yml`: `swift build`, `swift test`, `swift format lint`, and
`xcodebuild build` of the app on a macOS 27 runner.
