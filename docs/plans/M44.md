# M44 · Share links

Phase 2 of `collaboration-and-reach.md`: File › Share Link… turns a document, canvas,
branch or zone into a link anyone can open in a browser. The map is sealed on the Mac;
the key travels only in the link's `#fragment`, so the storage holds ciphertext and the
viewer site never sees the key. This milestone also adds the opt-in network service every
later phase uses, and the first part of the OpenNexus Server.

Decisions #4–#7 were confirmed on Oct 29, 2026 (D327–D330). The custom domain for the
viewer is still to be named; until then the viewer address defaults to
`https://jvaudio.github.io/opennexus/` (D327).

## Plan

### Swift package (NexusFormat, NexusNet, NexusCanvas, NexusKeys)

- **Sealed envelope** (`NexusFormat/Sealed.swift`). `ONX1`, a 4-byte big-endian header
  length, the header (compact canonical JSON: version, algorithm, content type, encoding,
  bundle version, created, optional expiry, and the KDF's name, iterations and salt for a
  password), a 12-byte nonce, then AES-256-GCM ciphertext and tag. Everything before the
  nonce is the associated data. The content is the M43 viewer bundle as canonical JSON,
  raw-deflated (`DecompressionStream("deflate-raw")` in browsers). A random 32-byte key,
  or PBKDF2-SHA256 from a password (iteration count recorded as a decision).
- **Sharing types** (`NexusFormat/Sharing.swift`), shared by the app and the service:
  `ShareDestination` (S3-compatible, GitHub Gist, OpenNexus Server; no secrets),
  `NetJob` (what the service is asked to do), `NetReply`, `NetLogEntry`, the XPC
  protocol, and `ShareLinkCode`, which writes and reads
  `https://<viewer>/s/#1.<destination>.<locator>.<key>`.
- **`NexusNet`** (new module, linked only into the service). An HTTP client on an
  ephemeral `URLSession` (no cookies, no cache) that checks every request and every
  redirect against the job's allow-list and records each request's host, method,
  purpose, status and bytes up and down. AWS SigV4 signing. Three destinations, each a
  `ShareTarget` (put, update, delete, test): S3-compatible (also Set Up CORS), GitHub
  Gist, OpenNexus Server. `NetService.perform(job, body)` is the whole service; the XPC
  wrapper only decodes and forwards.
- **The app's side** (`NexusCanvas/Sharing*.swift`). `ShareTransport` (the XPC client in
  the app, the in-process service in tests), `SecretStore` (Keychain; memory in tests),
  `ShareStore` (destinations and link records in the app container, never in the
  document), `NetworkLog` (the request log), `ShareCenter` (create, update, revoke,
  republish on save, sweep expired links). The bundle comes from the export pipeline
  (`exportModel` and `viewerOptions`), so scope, masking and Strip AI provenance are the
  Interactive HTML export's.
- **UI.** The Share Link sheet (Scope; notes, comments, attachments; masking as Export
  asks; password; expiry; destination; Create Link with progress), then the link with a QR
  code, Copy, Open in Browser and the share menu. Manage Share Links… (Copy, Update,
  Revoke, "Update when I save"). Settings › Sharing: destinations (add, edit, Test, Set Up
  CORS, remove), the viewer address, default expiry, the links. Settings › Privacy & Data:
  a Network section (the master switch and "Share links", both off), the log card counts
  real requests and gains Export Log…. With the network off, Share Link… explains why and
  offers Settings.
- **Commands.** `file.shareLink` Share Link… (⌃⌘S, File menu, palette, and the toolbar's
  share button) and `file.manageShareLinks` Manage Share Links….

### The app bundle

- `OpenNexusNet.xpc` in `Contents/XPCServices`: a new target in `make_project.py`
  (`App/Services/OpenNexusNet`, `App/Support/OpenNexusNet/`), sandboxed, with
  `com.apple.security.network.client`, linking the new `NexusNetKit` product. The app and
  its extensions don't link `NexusNet` and keep no network entitlement.

### OpenNexus Server (`server/`, a separate Swift package)

Hummingbird 2. `POST /v1/shares` (upload token) returns an id and a write secret;
`GET /v1/shares/{id}` for any origin; `PUT` and `DELETE` with the write secret;
`GET /v1/health`. Expiry, a size limit and a per-address rate limit; storage on disk or
in an S3-compatible bucket. Configured by environment variables. A Dockerfile, a Compose
example with Caddy for TLS, and a README for a home server (ZimaOS), a VPS and Fly.io.

### Web (`web/viewer-app`)

One route, `/s/`: parse the fragment, fetch the sealed object without credentials, open it
with WebCrypto and `DecompressionStream`, check the bundle and draw it with
`viewer-core`. Pages for a link that's turned off or expired, a wrong password, a damaged
or altered link, and one made by a newer OpenNexus. Built by esbuild into a static site;
a GitHub Actions workflow deploys it to Pages (it runs once pushed).

### Tests

- Swift: `SealedTests` (format, tampering, passwords, vectors shared with the browser
  code), `ShareLinkCodeTests`, `NexusNetTests` (SigV4 against AWS's published examples,
  the allow-list and redirects, the log, the Gist client against API fixtures, the S3 and
  server clients against a stub), `ShareCenterTests` (create, update, revoke, expiry,
  masking and Strip AI, records and secrets, republish on save, network off),
  `NetworkPrivacyTests` (the new rule), settings and keyboard tests.
- Server: route tests (auth, write secrets, expiry, size and rate limits, CORS), storage.
- Vitest: link parsing, the envelope (vectors from Swift; the browser's own seal byte for
  byte), error pages.
- Playwright: open share links in Chromium and WebKit (Firefox where it starts, D326) for
  each destination; wrong key, flipped byte, password, newer version, update, revoke and
  expiry.
- Docker (`scripts/test-share.sh`): MinIO and the server in Compose; a Swift test makes
  real links against both, and Playwright opens them.

### Built

- **Swift.** `Sealed` (the envelope, D331–D332) and the sharing types in NexusFormat;
  `NexusNet` (an ephemeral `URLSession` behind the allow-list, the log, SigV4, and the
  S3-compatible, Gist and Server destinations); `OpenNexusNet.xpc` (a new target in
  `make_project.py`, embedded in `Contents/XPCServices`); in the app, `ShareCenter`, the
  link store, Keychain secrets and the XPC transport; the Share Link sheet with a QR code,
  Manage Share Links, Settings › Sharing (destinations with Test and Set Up CORS, the
  links, the viewer address, default expiry), and the Network section and Export Log… in
  Privacy & Data; `file.shareLink` (⌃⌘S, File menu, toolbar share button) and
  `file.manageShareLinks`; republish on save.
- **Server** (`server/`). Hummingbird 2 with disk or S3 storage, the Dockerfile, the
  Compose example with Caddy, a README for ZimaOS, a VPS and Fly.io, and a Compose file
  for the tests with MinIO built from source.
- **Web** (`web/viewer-app`). The `/s/` page: fragment parsing, fetching without
  credentials, WebCrypto and `DecompressionStream`, the viewer, and the off, expired,
  damaged, newer, unreachable and password pages. 43 KB of script (15 KB gzipped) and
  8 KB of CSS. `.github/workflows/pages.yml` deploys it to GitHub Pages.
- **Tests.** `scripts/test-share.sh` runs MinIO and two servers in Docker, makes real
  links against them and opens them in Chromium and WebKit; `npm run fixtures` writes the
  share fixtures Playwright serves itself.

### Changed from the plan

- **MinIO is built from source** (D343): its images are no longer published.
- **No separate `ShareLinkCodeTests` or `ShareCenterTests`:** link fragments are in
  `SealedTests.linkFragments`, and `ShareLinkTests` covers what `ShareCenterTests` would.
- **The app keeps the log and the service keeps nothing** (D334, D335); secrets travel
  with each job instead of through a shared Keychain group.
- **Plain `http` only to this Mac** (D336), added after finding that a token would cross
  the network in the clear and the viewer couldn't read such a destination anyway.
- **The Gist destination is tested against fixtures in GitHub's documented shape** (D347),
  not a live account.
- **The Pages workflow is written but hasn't run:** nothing has been pushed, and the
  custom domain is still to be named (D327).

### Defects found

- The Server destination's Test sent an unsealed probe, which the real server refuses
  (415); the in-process stub had accepted it. Found by the live Docker run. The probe is
  now sealed with a throwaway key, and the stub refuses what the server refuses.
- The viewer's bounded inflate left its writer's promise rejected when it stopped early
  (too large, or bad data): an unhandled rejection, which Vitest reported. It's handled
  now; the reading side reports the error.
- Destinations accepted `http://` to any host (D336).

### Known gaps

- **The XPC hop wasn't driven in the running app.** The tests run the service's code
  in-process (`NetService`), and the built bundle was inspected, but no link has been
  made from the app's own Share Link sheet through `OpenNexusNet.xpc` yet. The first check
  by hand: turn the network on, add an OpenNexus Server at `http://127.0.0.1:18787`
  (`scripts/test-share.sh --keep`), choose Test, then Share Link….
- Firefox is unverified until Playwright ships a Firefox that starts on macOS 27 (D326).
- The viewer site isn't deployed: Pages has to be turned on for the repository (Source:
  GitHub Actions) and the workflow run by a push to `main`. Until the custom domain is
  named, links use `https://jvaudio.github.io/opennexus/`.
- A live gist hasn't been made (it needs a token). Readers fetch gists from GitHub's API
  without signing in, which GitHub limits to 60 requests an hour per address.
- Set Up CORS is tested against a stub of S3's API, not a real AWS, R2 or B2 bucket
  (MinIO allows every origin by default).
- Expired shares stay in a bucket or gist until the app next starts with the network on
  (D337); the viewer refuses them meanwhile.
- If a link's Keychain item is lost, the app can't update or revoke that link; its object
  has to be deleted at the destination by hand.
- The viewer site is in English only (D341), and the XPC connection checks no
  code-signing requirement until the app is Developer ID signed (D345).
