# M9 · macOS integration

## Plan

**Goal (README §11, §5 "Feels Apple-made", §6 package requirements; artboards 33 and 40):**
- Quick Look thumbnail and preview, and Spotlight indexing.
- App Intents: create from clipboard, export as PNG, add to inbox (plus convert to
  Mermaid, open Quick Capture, and run any registry command).
- Services and the Share extension, including the Safari clipper.
- Quick Capture as a global ✦N glass panel.
- Widgets.
- Handoff.
- The `nexus` CLI and MCP server (opt-in, stdio, local files only).

**Accept when:**
- The screens match artboards 33 and 40.
- The intents appear in Shortcuts.
- `nexus export`, `nexus validate` and `nexus mcp` work, and their tests pass.

### Signing and shared data

- **Local builds are signed with the developer's team from a gitignored
  `App/Signing.local.xcconfig`** (`DEVELOPMENT_TEAM`, Apple Development identity). The
  committed project still builds ad hoc for anyone else.
- **One App Group, `$(TeamIdentifierPrefix)com.opennexus`,** shared by the app, the
  extensions and the embedded CLI. Team-prefixed groups need no provisioning profile on
  macOS. It holds:
  - `Captures/`: a queue of captures from the Share extension and Safari clipper,
    drained by the app.
  - `Widgets/`: the inbox items and recent-map titles and thumbnails, written by the
    app.
  - `agent.json`: the MCP policy (enabled, allowed folders, read, edit and file
    permissions), written by the app from Settings and read by `nexus mcp`. An agent
    can't grant itself access by editing it, because other apps' group containers are
    protected by macOS.
- **Ad-hoc builds degrade gracefully:**
  - The Share extension falls back to a private named pasteboard.
  - Widgets show "Open OpenNexus".
  - `nexus mcp` reads `--config`, or the app container's copy.

### Package

- **The app writes `preview.png`** (the first canvas, at most 1,200 px wide) when it
  saves a package.
  - It is never written for encrypted documents, so the preview can't leak content.
  - It is added to the generated `.gitignore`, so Git diffs stay text-only.
  - Reading ignores it.
- **`SpotlightText`** (NexusFormat) extracts a title, the topic text, notes and labels.
  The Spotlight importer and the app's index both use it.

### `nexus` CLI (new `NexusAgent` target, headless and testable)

- **Commands:**
  - `nexus validate <file>`: the schema, plus each canvas's structure checks. Exits 1
    on issues.
  - `nexus export <file> --to <format> [--canvas <id>] [--out <path>] [--scale n]`
    - Every interchange format: md, opml, mermaid, plantuml, json, yaml, csv, docx,
      drawio, txt.
    - The visual formats (png, jpeg, svg, pdf) render through the app's own image
      exporter.
    - Output goes to stdout for text formats unless `--out` is given.
  - `nexus new "<title>" [--type mindmap|flowchart|…] [--out <path>]`
  - `nexus import <file> [--out <path>]`: any supported format to `.nexus`, printing the
    import report.
  - `nexus mcp [--config <agent.json>]`
  - `--help` and `--version`.
- **Argument parsing is hand-written,** with no package dependency (D89: no third-party
  code, and builds need no network).
- **Writes go through `NSFileCoordinator`,** so an open document in the app notices at
  once.

### MCP server

- **Transport:** JSON-RPC 2.0 over stdio, newline-delimited. Protocol versions
  `2025-06-18` and `2025-03-26` (the server answers with the client's version when it
  supports it). Handles `initialize`, `notifications/initialized`, `ping`,
  `tools/list` and `tools/call`; anything else gets `-32601`. Logging goes to stderr,
  never stdout.
- **Off by default.** When Settings › Integrations › Local MCP server is off,
  `initialize` fails with a message saying where to turn it on.
- **Tools (artboard 40):**
  - `list_maps` (in the allowed folders)
  - `read_map` (an outline or JSON, per canvas)
  - `add_topic` (parent by id or title path; text, note, labels)
  - `add_edge` (a relationship between two topics, with a label)
  - `set_style` (theme, node style, structure, and a topic's colour or shape)
  - `convert_type` (to any diagram type, using the same proposals as ⌥⌘T)
  - `export` (any format, to a file in an allowed folder, or text in the result)
- **Permissions:** read maps, edit maps, and create & export files, each Allow, Ask or
  Block.
  - Ask uses MCP elicitation when the client supports it. Otherwise the call fails
    with a clear message.
  - Paths are resolved (symlinks and `..`) and must sit inside an allowed folder.
- **Provenance:** every topic an agent creates or changes is marked AI (✦).
- **One undo step:** when the file is open in the app, the change arrives as a single
  undoable edit (see below).

### App

- **External changes:**
  - **No unsaved changes:** when the file changes on disk (an agent, the CLI, Git), the
    open document applies the difference as one undoable `Patch` instead of a silent
    revert.
  - **Unsaved changes:** the canvases the agent changed are merged, and edits to the
    same topic keep the user's version and are reported.
- **Quick Capture (✦N anywhere):**
  - **The shortcut:** a global hot key (⌃⌥⇧⌘N via the Carbon hot-key API, which needs no
    permission), and also in-app through the registry.
  - **The panel:** a non-activating glass panel with one field and the target line
    ("→ Inbox map · Product ideas"). ↩ saves, ⇥ cycles the target (Inbox, then recent
    maps), ⇧⇥ goes back, and Esc closes.
  - **Multi-line text** becomes inbox items, or a new map whose hierarchy follows the
    indentation (Settings).
  - **Start at login:** `SMAppService.mainApp`, plus a menu bar extra (Quick Capture,
    Inbox, recent maps). When launched as a login item, the app opens no windows.
- **The inbox:** captures are added to the Inbox map as one undo step if it's open,
  otherwise written to the file directly.
- **Services:** "New Map from Selection" and "Add to Inbox Map" (text), gated by
  Settings.
- **Share extension and Safari clipper:**
  - A compact sheet with the target map and an editable preview.
  - Text, links and images are accepted.
  - Safari pages arrive through a JavaScript preprocessor: title, URL, selection and
    readable text.
  - The app summarises the page on-device (Foundation Models) into a branch: title →
    key points → link. Without Apple Intelligence it falls back to the title, the
    selection or first paragraphs, and the link.
- **Spotlight:**
  - Documents are indexed when opened and saved, one item per topic, with the
    breadcrumb as the description ("Checkout redesign.nexus › Level 1").
  - Choosing a result opens straight to the topic.
  - Encrypted documents aren't indexed.
  - Turning the setting off deletes the index.
  - A Spotlight import extension adds topic text to the file's own metadata, so plain
    Finder and Spotlight search find `.nexus` files that were never opened.
- **Quick Look:**
  - A thumbnail extension (from `preview.png`, else rendered).
  - A preview extension (the rendered first canvas, its title and canvas list).
  - A lock card for encrypted packages.
- **App Intents (Shortcuts and Siri):**
  - Create Mind Map from Clipboard; Add Idea to Inbox Map; Export Canvas as PNG (a
    file in, an image out); Convert Map to Mermaid; Open Quick Capture.
  - Run OpenNexus Command, whose command parameter is an entity queried from the
    registry, so new commands appear without new code.
  - App Shortcuts phrases for each.
  - Gated by Settings › Shortcuts & Siri actions.
- **Widgets (WidgetKit):**
  - Inbox (small or medium: newest items and "+N more").
  - Recent Maps (medium: two to four thumbnails).
  - Taps open the inbox or that map through `opennexus://` links that carry a token,
    not a path.
- **Handoff:**
  - Document windows publish an `NSUserActivity` carrying the canvas and topic.
  - iCloud Drive documents use NSDocument's ubiquitous activity type.
  - Continuing an activity opens and selects the topic.
- **Settings › Integrations, wired:**
  - Allowed folders: Edit… opens a folder picker list.
  - Command-line tool: Install… shows the `ln -s` command for the embedded
    `Contents/Helpers/nexus`, with a Copy button. A sandboxed app can't write to
    `/usr/local/bin` itself.
  - Open code links in: links to source files open in Xcode, VS Code, Cursor, Zed or
    the default app.
  - The agent card's status line.

### Tests

- **`NexusAgentTests`:**
  - The CLI commands as functions: validate good and bad files, export every format,
    new, import.
  - The MCP protocol: initialize and version negotiation, tools/list schemas, every
    tool, errors, ping, unknown methods.
  - Permissions: allow, block, and ask with and without elicitation.
  - Folder confinement: `..`, symlinks, sibling prefixes.
  - The disabled server; provenance flags.
- **End to end:** the built `nexus` binary as a subprocess.
  - `validate` and `export --to mermaid` / `--to png`.
  - A scripted `nexus mcp` session over pipes.
- **Format:** `preview.png` presence and absence (encrypted); Spotlight text; the
  capture queue.
- **Canvas:**
  - Quick Capture parsing (single line, multi-line as items or a new map, target
    cycling).
  - An inbox append as one undo step.
  - External-change reconciliation: one undo, a dirty merge, a conflict report.
- **App:**
  - The build contains `Metadata.appintents` with every intent.
  - `pluginkit` lists the extensions; `qlmanage -t` makes a thumbnail.
  - Snapshots of Quick Capture, the widgets, the Quick Look preview and Settings ›
    Integrations, compared with 33 and 40.

Built:
- **NexusAgent (new target) and the `nexus` CLI:**
  - Commands: `validate` (checks the files on disk, not a re-serialisation), `export` (15 formats through the app's own exporters), `new`, `import`, `mcp`, `--help` and `--version`.
  - The MCP server (JSON-RPC 2.0 over stdio; protocol 2025-06-18, 2025-03-26 and 2024-11-05) with seven tools.
  - Permissions (Allow / Ask / Block; Ask through MCP elicitation), folder confinement (symlinks, `..`, sibling prefixes), and AI provenance on every agent edit.
  - Coordinated writes that refresh `preview.png`.
- **Package:** `preview.png` (Quick Look) written on save, never for encrypted documents, and listed in the generated `.gitignore`.
- **NexusCore / NexusCanvas:**
  - `DocumentMerge` (a three-way merge of disk and unsaved edits) and `DocumentStore.mergeExternal`, as one undo step.
  - `HeadlessExport`; Quick Capture's model and view; `CaptureComposer` and `CaptureTargets`; `CodeLinks`; `AgentFolders` and the Allowed Folders sheet.
- **NexusFormat:** `SpotlightText`, `AppGroup`, `Capture` and `CaptureQueue`, `WidgetSnapshot`, `AgentPolicy` and `ExtensionSettings`.
- **NexusAI:** `PageSummary` (the clipper's key points, on-device, with a fallback).
- **NexusWidgetsUI (new):** the widgets' views, shared by the extension and the tests.
- **App:**
  - `Integrations`: Spotlight items per topic that open on the topic; widget data; `opennexus://` links; Services ("New OpenNexus Map from Selection", "Add to OpenNexus Inbox"); draining Share and Safari captures into the Inbox or a recent map as one undo step; writing the agent policy.
  - `QuickCapture`: a Carbon hot key that follows Settings › Shortcuts; the non-activating glass panel; the menu bar item; Start at login (`SMAppService`, windowless when launched at login).
  - App Intents.
  - Handoff (an iCloud document activity type, plus the canvas and topic in the activity).
  - External changes merged instead of silently reverted.
  - Code links opening in Xcode, VS Code, Cursor or Zed at the line.
  - Install… for the CLI.
- **Extensions (new targets):**
  - Quick Look preview (data-based HTML with the rendered map) and thumbnail (`preview.png`, else rendered; a lock card when encrypted).
  - Spotlight importer (`CSImportExtension`).
  - Share extension with the Safari clipper (a JavaScript preprocessor).
  - Widgets (Inbox, Recent Maps).
- **Project:** `App/tools/make_project.py` generates the seven-target project. `App/Config/Base.xcconfig` signs ad hoc, unless a gitignored `Signing.local.xcconfig` names a team (this Mac's build is signed with team SF9QX9G45C; the ad-hoc build was checked too).

Defects found during M9 and fixed:
- NSDocument's default handling of an external change silently reverts, which would have wiped undo after every agent edit. It's now a merge, as one undo step.
- Exports, previews and the CLI drew paired themes dark when the Mac was in dark mode (follow-system leaked into offscreen rendering). They now draw the canvas's own theme.
- The Quick Look HTML reply had no text encoding set (it's explicit now). `qlmanage -o` still crashes writing attachment-based previews to disk, so the preview was checked in the real panel instead.
- An unsigned build expanded the App Group to a bare `com.opennexus`, which would prompt for access to another app's data. Without a team prefix it now counts as no group, and the fallbacks apply.

Tests: 302 test functions across 9 targets, all passing (`swift test`; lint clean). New this milestone:
- `NexusAgentTests` (12): the protocol, every tool, permissions and elicitation, confinement, the CLI commands, and the built binary.
- `IntegrationTests` (8): capture parsing, the inbox append as one undo step, target cycling, Spotlight text, the agent policy, code links, the capture queue and widget snapshot, and previews of encrypted documents.
- `ExternalChangeTests` (3): a clean document takes the disk version as one undo; unsaved edits merge, and conflicts keep the user's version; canvases added and removed on disk.
- `IntegrationSnapshotTests` (2, env-gated).
- Performance unchanged: key→caret 11.2 ms median, 1k reflow 28.3 ms.

Checked on this Mac, outside the test suite:
- `pluginkit` lists all five extensions.
- `qlmanage -x -t` made thumbnails both from `preview.png` and by rendering.
- The Quick Look panel showed the preview.
- `mdimport -e` lists the Spotlight importer for `com.opennexus.document`.
- The App Group container is `SF9QX9G45C.com.opennexus`, and the CLI is signed by the same team.

Not verified by running the system feature:

- Widgets in the widget gallery, the Share sheet and Safari clipper, Services, Handoff, and Quick Capture's global hot key and menu bar item. Each was built and unit-tested where its logic allows, but needs a person at the keyboard (or a second Mac, for Handoff).
