# M13 · Zone and Excel export

## Plan

**Goal (Xmind parity review, export gaps):**
- A zone exports and prints on its own, as Xmind's "Export by Zone" does.
- Excel export (.xlsx) beside Word, PowerPoint and CSV.
- Decide whether relationships can connect to a zone, as in Xmind 26.03.

**Accept when:**
- Export Zone… and Print Zone… are on the zone's context menu, in the Format panel's
  zone section and in ⌘K.
- A zone exports as PNG, JPEG, SVG and PDF, cropped to the zone and its contents, and
  prints through the existing print path.
- Excel export writes a valid workbook: one sheet per canvas, rows in outline order.
- Zone relationship endpoints are built, or recorded as a gap with the reason.

### Zones

- **A zone scope** (`ImageExporter.Scope.zone`, with `Options.zone`) beside canvas,
  selection and branch. It keeps the zone's members and their branches, and the zone
  itself, even when it is empty. Positions come from the full layout, so the crop is
  the zone as it looks on the canvas.
- **Print:** `PrintLayout.Content.zone`, with `Options.zone`. The header reads
  "Map – Zone", and the notes appendix holds only the zone's topics.
- **Entry points:**
  - Right-click a zone: Export Zone… and Print Zone…. This is the canvas's first context
    menu; elsewhere right-click still does nothing.
  - The Format panel's zone section: two buttons.
  - ⌘K and the File menu: `file.exportZone` and `file.printZone`. They act on the
    selected zone or the zone holding the selected topic, and are hidden otherwise.
- **The sheets:** Export Zone… opens the export sheet on the last visual format (PNG if
  the last one wasn't visual), with Zone selected in the scope picker. Print Zone… opens
  the print sheet with Zone content. Zone appears in either picker only when a zone is
  being exported or printed.

### Excel

- **`ExcelFormat`** (NexusInterchange) writes SpreadsheetML by hand with `ZipWriter`:
  `[Content_Types].xml`, `_rels/.rels`, `docProps/core.xml`, `xl/workbook.xml`,
  `xl/_rels/workbook.xml.rels`, `xl/styles.xml` and one `xl/worksheets/sheetN.xml` per
  canvas.
- **Rows:** a header, then one row per topic in outline order (the main tree, then
  floating topics' branches).
- **Columns:** Level, Path, Topic, Note, Labels, Markers, To-do. Technical canvases add
  Type, STRIDE, Risk and Status.
- **The export sheet:** Excel under DOCUMENT, with a description and a tab-separated
  preview; Copy puts the rows on the clipboard to paste into a spreadsheet.
- **Headless:** `nexus export --to xlsx` and the MCP `export` tool.

### Relationships to zones

- Investigate the model, layout and Connect mode. Build it if it fits; otherwise record
  the gap.

## Results (2026-10-20)

### Acceptance

| Criterion | Result |
| --- | --- |
| Export Zone… and Print Zone… on the context menu, Format panel and ⌘K | ✅ Right-click on a zone, two buttons in the zone section, and two registry commands (palette and File menu). |
| A zone exports as PNG, JPEG, SVG and PDF, cropped to the zone | ✅ Through the shared scope: the image is the zone's rectangle plus padding; the SVG holds only the zone's topics; the PDF page is the zone's size. |
| A zone prints through the existing print path | ✅ `PrintLayout.pdf` with Zone content: fit, actual size or tiled, with its own notes appendix. |
| Excel export writes a valid workbook | ✅ Every part parses as XML, the cells read back as the sample map, and Quick Look's spreadsheet viewer renders it (`qlmanage -t` on an export from `nexus export --to xlsx`). |
| Zone relationships built or recorded | ⚠️ Recorded as a gap (D158); see below. Built in M15 (D160–D162). |

### Built

- **Zone scope** for every visual exporter and the print layout (D155). The scene keeps
  the exported zone's frame even when its member list is empty.
- **The zone context menu** (D156), through `performRegistryCommand`, so a mouse use
  counts toward the key tip like any menu item.
- **`ExcelFormat`** (D157), with the sheet's preview and Copy as tab-separated rows.
- **`nexus export --to xlsx`** (alias `excel`) and the MCP tool (D159).

### Tests

340 tests across 9 targets, all passing (`swift test`; lint clean). New this milestone:
- `ExporterGoldenTests.excelExport`: the package has exactly the required parts, each
  part parses, the content types and workbook relationships name every sheet, the rows
  match the launch-plan sample (order, level, path, note, labels, markers, to-do), and
  the threat-model sample gets Type, STRIDE, Risk and Status.
- `ExporterGoldenTests.excelSheetNamesAndUnsafeText`: forbidden and over-long sheet
  names, duplicate names ignoring case, and a control character in a topic.
- `FileFlowTests.zoneExportCropsToTheZone`: the zone's content rectangle and image size,
  an empty zone, SVG content, and the PDF page size.
- `FileFlowTests.zoneCommandsMenuAndPanelEntryPoints`: ⌘K hides and shows the commands,
  the right-click menu, the export sheet's zone scope across a format change, the saved
  file name, the scope not being remembered, and Print Zone's pages and appendix.
- `FileFlowTests.excelExportFromTheSheet`: the sheet's file, preview and file name.
- `AgentTests.exportEveryFormat` now covers `xlsx`.
