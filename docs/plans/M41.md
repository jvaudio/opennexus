# M41 · Guide mode

An optional panel that shows the steps toward a well-formed diagram, where the canvas
stands, and one tip (`starters-guide-present.md`, Feature 2).

## Plan

**Accept when:**

- **A1 · Guides are data.** JSON guides validated by a published schema; first wave: mind
  map, flowchart, data flow, architecture, threat model (with STRIDE suggestions).
- **A2 · Matcher.** `GuideMatcher.progress(canvas, guide, selection)` is pure (NexusCore).
  Match kinds: node type (inferred for untyped maps), kind and depth, named, each, edge
  (labelled), boundary, rules. Unit tests cover add, rename, delete, reparent, undo/redo
  and untyped maps.
- **A3 · Panel.** ⌃⌘G and View › Guide: header (type, "n of m", close), steps with their
  states (upcoming, current pulsing once, done, skipped), a mini diagram for tree types, a
  tip with Skip, and Present / Hide Guide on completion. It shares the trailing slot with
  the AI panel. Tips quote command ids, drawn in the active profile's keys.
- **A4 · Never in the way.** Matching runs after a change, coalesced to the next run-loop
  turn; typing latency is unchanged with the guide open (`keyToCaret`).
- **A5 · Storage.** `canvas.guide = {id, skipped}`, only when not default; Skip is an
  undoable edit. Visibility is window state.
- **A6 · Type control.** Format › Data › Type, backed by a registered Set Node Type….
- **A7 · Picker.** A Guided badge and Start with Guide, remembered per starter.
- **A8 · Quality.** `swift test` and `scripts/lint.sh` pass, and the app builds.

### Known gaps

- **No ghost suggestion.** Clicking an unmet step shows its tip and keys; the plan's ghost
  through the AI suggestion UI isn't drawn.
- **No pixel goldens of the panel.** Like the rest of the chrome, it's reviewed through
  env-gated renders (`NEXUS_SNAPSHOT_DIR`), not compared in CI.
- **Not driven by hand in the running app.** No live VoiceOver walk or `axaudit` run; step
  rows are labelled buttons with their state as the value.
- **The 2 ms budget is met for the mind map guide only** in a debug build; the typed guides
  are held to a quarter of the scene rebuild instead (D297).
- **Button titles ("Skip Step", "Present") stay English in the pseudo-language**, as all
  SwiftUI literal titles do.
