# M14 · Comments and legends

## Plan

**Goal (Xmind parity review):** the Xmind importer skipped two things people use when
they review maps together.
- **Comments on topics:** a review thread beside a topic, with author and time.
- **Map legends:** a box listing the markers and labels a canvas uses, with a custom
  description per marker.

**Accept when:**
- **A1 · File format:** comments and the legend are optional, round-trip byte-identically,
  validate against the schema, and older files open and save unchanged.
- **A2 · Comments in the app:** Comment… has a key and a menu home and is in the palette.
  Comments can be added, edited and deleted, each as one undo step, and show as a badge
  with a popover thread. The Notes tab or a filter finds them, and VoiceOver reaches them.
  The author defaults to the Mac user's full name and can be changed in Settings.
- **A3 · Legends in the app:** the legend is a movable box on the canvas, shown and hidden
  from View and the palette, with editable marker descriptions, and drawn in image and
  PDF exports.
- **A4 · Xmind import:** comments (Zen and XMind 8) and legends (descriptions and
  position) import instead of being skipped.
- **A5 · Exports:** a recorded choice of which exports carry comments, with at least
  Markdown and Word as an appendix.
- **A6 · Quality bars:** strings are localised, the accessibility audit is clean, and there
  are no network APIs.

### Comments (NexusCore)

- **`Node.comments: [TopicComment]`**, oldest first, omitted when empty (D3). Each comment
  is `{author, date, text}`:

  ```json
  "comments": [
    { "author": "Ana", "date": "2026-10-20T14:03:00Z", "text": "Drop it?" },
    { "author": "Lee", "text": "Check margins", "resolved": true }
  ]
  ```

  - `date` is ISO 8601 with a time zone, kept as written so a file round-trips byte for
    byte. New comments write whole seconds in UTC. An unknown date (some imports) is
    omitted. `instant` parses it.
  - Unknown keys inside a comment round-trip through `extra` (D4), like `resolved` above.
  - No ids, replies or resolved state. An imported reply follows the comment it answers.
- **Schema:** a `comment` definition (author and text required; a date pattern) and
  `node.comments`, in both copies.
- **Search and filters:** the filter gains `comment:` (`yes`, `no`, an author, or words
  in the text). Find with "+ Notes" searches comment text, and replace works on it.
  `CanvasCounts` counts commented topics and comments.
- **Masking:** comment text is scanned like notes; authors count as names.

### Comments in the app (NexusCanvas)

- **Comment… (⌃⌘N):** Insert menu, palette, and the topic's ❝ indicator. It opens a
  popover thread:
  - each comment with its byline ("Ana · 20 Oct 2026, 14:03", in the reader's time zone)
    and Edit and Delete buttons;
  - a field to add one ("Comment as Ana"), with ⌘↩ adding it.
- **Undo:** add, edit and delete are one step each. Clearing a comment's text deletes it.
- **Badge:** a ❝ indicator at the end of the title row, with a small count when there's
  more than one. It's drawn on screen, in image and PDF exports, and in SVG.
- **Notes tab** (⌃⌘3): lists topics with a note or comments, each comment with its byline.
  The counts popover gains a Comments row.
- **Settings › Editing › Comment author:** empty uses the Mac account's full name.
- **VoiceOver:** a topic reads "2 comments". A Comments rotor walks commented topics, and
  each topic has a Comments action. The popover's rows read "Comment by Ana …".

### Legends (NexusCore and NexusCanvas)

- **`Canvas.legend: Legend?`**, written only once a canvas has had one:

  ```json
  "legend": { "visible": true, "position": { "x": 320, "y": -140.5 }, "markers": { "flag-red": "Blocked" } }
  ```

  - What it lists is derived, not stored (`Canvas.legendContents`): markers in use in
    library order (priority, progress, flags, stars, symbols, people), then unknown ids;
    labels in first-use order.
  - Only markers take descriptions. An empty description shows the marker's own name
    (`MarkerLibrary.name`, localised).
  - No `position` means beside the map: 48 pt right of the content, top-aligned.
- **On the canvas:** `SceneLegend` is laid out by the scene builder and drawn by a
  `LegendLayer` above the topics, with the theme's ink and canvas colours. Dragging it
  stores its top-left corner as one undo step. Double-clicking opens the editor.
- **Commands:** View › Legend (⌥⌘L) shows and hides it, making one the first time.
  View › Edit Legend… opens a popover: Show on canvas, a description field per marker,
  the labels in use, and Reset Position.
- **Exports:** the legend is part of the scene's bounds, so canvas-scope PNG, JPEG, PDF,
  print and Word's images draw it through the same layer, and SVG writes a `legend`
  group. Branch, selection and zone exports leave it out.
- **VoiceOver:** one element after the canvas's topics, read as "Legend: Priority 1. Red
  flag, Blocked. Label Q4.", whose press opens the editor (actions Edit Legend and Hide
  Legend).

### Xmind import (NexusInterchange)

- **Comments** (D161), instead of `report.skip("Comment")`:
  - Zen: the topic's `comments` as a list, a single object, or an object holding
    `comments` or `items`; text in `content`, `text`, `body` or rich text; author as a
    string or `{name}`; time as epoch milliseconds or seconds or ISO 8601; `replies`
    flattened after their comment.
  - Zen: a top-level `comments.json`, keyed by topic id or a list naming `objectId`.
  - XMind 8: `comments.xml` (`<comment object-id author time><content>`).
  - The report counts comments ("4 comments"); ones on a sheet or a missing topic, and
    unreadable shapes, are listed.
- **Legends** (D165), instead of `report.skip("Legend")`: Zen `legend` (`visibility`,
  `position`, `markers` as an object or a list) and XMind 8 `<legend>` with
  `<marker-descriptions>`. Marker ids map through the existing table. Unmapped markers
  and group names are reported.

### Built

- **NexusCore:** `TopicComment` and `Node.comments`; `Legend`, `Canvas.legend` and
  `legendContents`; the `comment` filter field, comment search and replace, comment counts.
- **NexusAI:** masking scans comments and authors.

- **NexusKeys:** Comment… (⌃⌘N), Legend (⌥⌘L) and Edit Legend….
- **Schema:** `comment`, `node.comments` and `canvas.legend` (additions only).

### Changed from the plan

- **The legend lists labels without descriptions.** Xmind's legend describes markers only.
- **No separate Comments tab:** the Notes tab lists comments, and the filter has
  `comment:`.

### Defects found during M14 and fixed

- **The filter's `comment ~ text` didn't parse** (the filter has no `~` operator), so
  `comment:` also matches words in the text.

- **The legend can't be moved from the keyboard** except back beside the map (Reset
