One map, nine ways to draw a node

A node style sets shape, fill, border, weight and branch-line character. The colour theme supplies the colours and the structure sets the layout, so all three combine freely. Pick it in Format › Map › Node style, the palette (“Node style…”) or ⌥⌘S, which cycles with a 300 ms morph. Try it live in the P0 prototype’s Style menu.
