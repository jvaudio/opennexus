# M2 · Styling

## Plan

**Goal:** the twelve themes and the theme builder, the nine node styles with ⌥⌘S
cycling, the Format panel (Style, Map, Data) with every control on FMT-1…3, quick
styles, copy / paste / reset / update style, Smart Color, and the custom colour theme
editor with a live contrast check.

### Model (NexusCore)

- `TopicStyle`: a typed, all-optional style record (shape, fill, border, corner radius,
  shadow, text, numbering, width, image position, branch line, spacing) with unknown-key
  passthrough. Colours are stored as hex strings or the token `branch`.
- `Node.style` becomes `TopicStyle?`; nodes gain `quickStyle` and `metadata` (Data tab).
- `CanvasStyle` gains the Map tab: colour theme mode and palette, coloured branch, single
  branch colour, background and pattern overrides, global and CJK fonts, branch line
  width, auto balance, compact, justify, and per-level styles (Update Style › all level-N
  topics). `CanvasLayout` gains the advanced layout toggles.

### Resolution (NexusTheme)

`StyleResolver` merges, highest priority first:

1. node override (`Node.style`)
2. quick style (`Node.quickStyle`)
3. branch level (`CanvasStyle.levels[depth]`)
4. node style preset (Outline … Minimal, as data)
5. theme
6. defaults

The result is a `NodeAppearance` (shape, fill or gradient, border pattern, radius,
shadows, glow, underline, typography, text colour) plus a `BranchLineStyle`. Text colour
always passes WCAG AA against its effective background (auto contrast, on by default):
colours that would fail are toned toward ink or white until they pass.

Also: 12 `Theme`s, 6 colour palettes × 4 colour-theme modes, 8 built-in quick styles,
32 shapes (parsed from FMT-1's path data, with parametric versions of the common ones),
and a `.nexustheme` JSON codec.

### Rendering (NexusCanvas)

`NodeLayer` draws any shape path, fills (solid / tint / gradient), border patterns
(solid, dashed, dotted, hand-drawn wobble, double), soft and hard shadows, glow, and the
underline style. Branch lines take shape, width, colour, dash, glow and end caps from the
resolved style; underline nodes attach lines to their baseline. Style changes cross-fade
over 300 ms (`glide`) while positions spring.

### UI

- Format panel (⌘I): SwiftUI inspector on the right with Style / Map / Data tabs.
- Theme builder sheet and custom colour theme editor, both with live contrast badges.
- Commands: ⌥⌘S, ⌥⌘C / ⌥⌘V / ⌥⌘R, ⌃⌥1–8, ⇧⌘R, ⌘I; toolbar theme menu lists all 12.

### Tests

- Snapshot tests: the NS sample map in 9 node styles × 4 required themes, rendered
  offscreen and compared with committed goldens (tolerance), plus a contact sheet.
- Contrast: every theme × node style × role passes AA; High Contrast passes AAA.
- Resolution order (each layer overrides the one below), `TopicStyle` JSON round trip
  and unknown keys, `.nexustheme` round trip, copy / paste / reset / update style and
  quick styles are single undo steps.

Built:
- 12 themes (Classic, Paper, Graphite, Midnight Neon, Blueprint, Whiteboard, Pastel, High
  Contrast, Mono Print, Solarized, Skeleton, Skeleton Dark) as Codable data with light/dark
  counterparts, per-theme font, line shape and width, radii, contrast target and
  per-diagram colour modes; `.nexustheme` export and import.
- 9 node styles as style layers per role plus branch-line character; ⌥⌘S cycles with a
  300 ms cross-fade morph.
- `TopicStyle` model and the six-layer resolver with auto contrast (text toned, and
  mid-tone fills deepened when neither white nor ink text can pass).
- 32 shapes (SVG path parser with arc support, parametric common shapes), fills (solid,
  tint, gradient), borders (solid, dashed, dotted, hand-drawn wobble, double), soft / hard
  / glow shadows, underline nodes with baseline-attached lines, tapered and dotted lines,
  glowing lines, end caps, numbering (7 formats, tiered), text case, per-branch spacing,
  compact, justify, auto balance, background and pattern overrides, global font.
- Format panel (⌘I) with Style / Map / Data tabs and every FMT-1…3 control; skeleton
  gallery (24); theme builder with live contrast badge; colour theme editor with
  "AA on all 6" check; custom themes Edit · Rename · Duplicate · Delete · Import.
- Commands ⌥⌘S, ⌥⌘C / ⌥⌘V / ⌥⌘R, ⌃⌥1–8, ⇧⌘R, ⌘I. Theme-library changes ride on patches
  (`themeBefore` / `themeAfter`), so they undo like everything else.

Tests: 99 test functions across 6 targets, all passing.

Known gaps carried forward:
- Rich text on partial selections (B / I / U / S apply to the whole topic for now; the
  editor is plain text until M3's rich-text pass).
- "Free layout", "Branch free-positioning" and "Allow topic overlap" are stored and
  shown, but drag-to-position arrives with drag-and-drop in M3.
- Image position is stored; images arrive with M3's enrichments.
- Hard shadows render with the correct offset on screen; the offscreen golden renderer
  draws them mirrored (consistent run to run, so goldens stay valid).
